# YouTube API Quota Review Screencast Guide

To obtain a YouTube Data API quota increase beyond the default 10,000 units/day, YouTube compliance reviewers require a brief video demonstration (screencast) showing that your application uses the requested API scopes legitimately.

Follow these steps to record a screencast that meets all compliance requirements.

---

## 🎬 Prep Work (Before Recording)
1. **Choose a Screen Recorder**: Use OBS Studio, Windows Game Bar (`Win + G`), macOS QuickTime, or Zoom (share screen and record). Ensure your resolution is clear and terminal text is legible.
   > [!NOTE]
   > **Face recording is NOT required.** Reviewers only need to see your computer screen, terminal window, browser during authorization, and YouTube Studio dashboard.
2. **Clear Open Tabs**: Open a clean browser window. Open your terminal panel.
3. **Verify Files**: Ensure your OAuth 2.0 client secret JSON is saved as `config/youtube_client_secrets.json`.
4. **Locate Your Channel Link**: Have your YouTube channel link ready to paste in your email reply.

---

## 🎥 Recording Script & Steps

### Step 1: Start Recording (0:00 - 0:15)
* Start the recording showing your clean desktop, code editor, or terminal.
* *Action*: Show the project structure, demonstrating that this is an autonomous Python content engine running locally.

### Step 2: Show the OAuth Consent & Scope Screen (0:15 - 0:45)
* *Action*: Navigate to your project directory and run the authorization script:
  ```bash
  ACTIVE_CHANNEL=demo_channel python execution/authorize_youtube.py
  ```
* *Action*: The browser will automatically open showing the Google login screen. Log in to the Google account associated with the channel.
* *Action*: Show the permissions consent list. Ensure the recording captures the specific scopes requested:
  - **Manage your YouTube videos** (`youtube.upload` and `youtube`)
  - **View YouTube Analytics reports** (`yt-analytics.readonly` and `youtube.readonly`)
* *Action*: Click **Continue** to approve the permissions. Show the success message in the browser: *"The authentication flow has completed. You may close this window."*
* *Action*: Show the terminal output confirming: `✅ Authorization complete! Token saved to channels/...`

### Step 3: Run the Test Upload Pipeline (0:45 - 1:15)
* *Action*: In your terminal, run the pipeline with upload enabled:
  ```bash
  AUTO_POST_YOUTUBE=True python execution/run_pipeline.py --channel demo_channel
  ```
* *Action*: Watch the script execute:
  - Generating script & synthesizing neural audio.
  - Assembling 1080x1920 video container.
  - Uploading video to YouTube Data API (`youtube.videos().insert()`).
  - Setting custom thumbnail frame (`youtube.thumbnails().set()`).
  - Printing the final YouTube Watch URL.

### Step 4: Verify the Upload in YouTube Studio (1:15 - 1:45)
* *Action*: Open **YouTube Studio** (`studio.youtube.com`), go to the **Content** tab.
* *Action*: Point out the uploaded test video. Show that:
  1. It is marked as **Unlisted** (or Private).
  2. It has the **Custom Thumbnail** set correctly.
  3. The title and description match the automated metadata generated by the script.

### Step 5: Stop Recording & Save
* End the recording. Keep the video length under 2 minutes.
* Upload the video to Google Drive or YouTube (as Unlisted), and copy the sharing link.
